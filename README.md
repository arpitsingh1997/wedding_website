# Dharmi & Arpit — Wedding Website

A cinematic opening experience for a luxury Indian wedding invitation site.

## Stack

- **Next.js 15** (App Router)
- **Tailwind CSS**
- **Framer Motion**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Tap the ribbon bow on the envelope to begin the reveal animation.

## Opening experience

1. Full-screen envelope with illustrated bow and ribbon
2. Ambient cherry blossom petals, watercolor washes, and soft shimmer
3. Click the bow to untie the ribbon and open the envelope
4. Seamless transition into the invitation copy and navigation

## Project structure

```
src/
  app/              # Layout, global styles, home page
  components/
    opening/        # Opening experience components
  lib/
    motion.ts       # Shared easing and animation variants
```
